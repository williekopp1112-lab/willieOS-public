Objective
Frame the evaluation criteria before competition enters.
  • Lead with landmine questions 1, 3, and 5 (data retention, cloud risk, context window)
  • Ask about their agent strategy — if they mention MCP, note it as alignment
  • Understand compliance requirements early (FedRAMP? HIPAA? ISO 42001?)
  • If Azure-heavy, acknowledge it and position multi-cloud as risk mitigation, not replacement
  • Don't lead with pricing. Let OpenAI own "cheap" positioning. You own "enterprise-grade."
Objective
Win the technical team by demonstrating capabilities OpenAI can't match.
  • Run the POC on their hardest use case — the one that requires the most context
  • Demo 1M context window with their actual data (full codebases, long documents)
  • Show prompt caching economics — run the same prompt twice and show the 90% cost reduction
  • Demo MCP integration if they have existing tool infrastructure
  • Provide the 99.99% uptime SLA commitment and ask them to get the same from OpenAI in writing
  • If fine-tuning comes up: show how 1M context + caching solves their use case without it. If it doesn't, acknowledge honestly — credibility matters.
Objective
Justify the price premium with TCO and risk arguments.
  • Build the TCO model: raw token cost + RAG infrastructure + migration cost + engineering time + outage cost
  • Highlight the Opus price drop (3x reduction from 4.0 to 4.7) — shows the gap is closing
  • Offer prompt caching + batch stacking math for their specific workload — show the path to 5% of list price
  • Position multi-cloud as procurement leverage: "Run Claude on AWS or GCP, whichever gives you a better deal"
  • If they push hard on price: AWS Marketplace billing may count against existing cloud commitments
Objective
Remove final objections and arm the champion.
  • Provide ISO 42001 certificate and Constitutional AI documentation for compliance
  • Offer the 99.99% SLA terms for the legal team
  • Share the 1,000+ enterprise customer reference and Fortune 10 numbers for exec buy-in
  • If OpenAI makes a last-minute price cut: "Price cuts when you're losing market share aren't confidence-inspiring."
  • Final framing: "Anthropic is the enterprise choice. OpenAI is the consumer choice. Which matches what you're building?"

Competitive Landmines
Plant these early in discovery calls to frame the evaluation
# Question to Ask What It Exposes Anthropic Advantage
1 "How long does your current AI vendor retain your API data by default?" Most buyers don't know OpenAI's 30-day default. Learning it in the room creates urgency. 7-day default — no special agreement needed.
2 "Have you had to rebuild integrations due to model deprecations in the last 12 months?" OpenAI deprecated Assistants API + retired multiple models from ChatGPT. Real cost, real pain. Three model tiers, consistent naming, no mass deprecations.
3 "What's your fallback plan if your primary AI cloud goes down?" Single-cloud (Azure-only) is a concentration risk. OpenAI = Azure-only. Multi-cloud: AWS Bedrock + GCP Vertex + Microsoft Foundry.
4 "How does your AI vendor's safety testing compare to your own governance requirements?" Surfaces ISO 42001, Constitutional AI, published constitution. Most buyers haven't seen these from OpenAI. Published 23K-word constitution + ISO 42001 (AI-specific governance).
5 "What's the largest document or codebase you need to process in a single API call?" Anything over 128K tokens is an Anthropic-only play. 1M tokens at flat rate. No chunking. No RAG workaround.
6 "Are you building agent-based workflows? What protocol are you using for tool integration?" If they say MCP, they're already in Anthropic's ecosystem. If not, you introduce the standard. MCP is the industry standard — even OpenAI adopted it.
7 "How important is it that your AI vendor is financially sustainable long-term?" OpenAI's $12B quarterly loss and $852B valuation (with investor skepticism) vs Anthropic's leaner operation. Anthropic trains at 4x lower cost, passed OpenAI in revenue.
