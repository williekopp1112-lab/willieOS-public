Dispatch Engine

Four specialist agents, auto-routed

Gary classifies the request, selects the right agent, and routes based on output type. Code changes go to the Engineer. Research goes to the Researcher. Design goes to the Designer. Documents go to the Writer.

◉
Researcher
Web search, deep research via Perplexity, Brave, and Playwright browser automation. Produces analysis documents and intel briefs.
◊
Designer
v0 Design Portal and Claude Design integration. Generates mockups, interactive prototypes, and production-ready HTML.
✍
Writer
Documents, presentations (PPTX), spreadsheets, and pitch decks. Uses python-pptx for native PowerPoint editing.
▽
Engineer
Claude Code CLI for code changes, git operations, and building interactive deliverables. Max-covered at $0 per dispatch.

Project Wizard

Multi-phase projects with stage-gate review

Complex work is decomposed into phases with dependencies, parallel execution, and quality checkpoints between each stage.

01
Pre-flight Dialogue
Gary asks clarifying questions, sets acceptance criteria
02
Agent Build
Specialist agents execute with full tool access
03
Post-flight Review
Validator agent checks output against criteria
04
Pass / Gaps / Escalate
Auto-promote, request revision, or escalate to user

Multi-agent chains auto-promote between stages. Each agent receives a structured handoff contract with the previous phase's output, acceptance criteria, and context window. The validator is a real agent (not a simple check) that evaluates deliverables against the original requirements.

Why It Matters

Proof of operational AI literacy

WillieOS is not a side project or a demo. It is a production AI system that handles real work every day—triaging email, scheduling meetings, dispatching research, building deliverables, and learning from each interaction.

It was built by an enterprise seller who spent 17 years helping companies adopt technology platforms. The question he kept hearing was: "How do we actually operationalize AI?" So he built the answer.

This is what digital native architecture looks like when applied to personal productivity: local-first data sovereignty, multi-model orchestration, autonomous agent dispatch, and a system that improves itself without human prompting.
