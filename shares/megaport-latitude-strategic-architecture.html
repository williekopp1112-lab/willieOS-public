Executive Summary

▾

In November 2025, Megaport (ASX: MP1) completed its acquisition of Latitude.sh for US$150M upfront plus up to US$150M in performance-based earnouts, creating the world's first fully integrated Compute + Network-as-a-Service (CaaS + NaaS) platform.

Latitude.sh brought annualized recurring revenue of US$43.1M at acquisition and has already secured a US$25M compute contract post-close — validating enterprise demand for the combined platform. The merged entity spans 1,000+ data centers across 26 countries with 125+ data center operator partnerships.

Strategic Insight This is not a bolt-on acquisition. By combining Megaport's software-defined networking fabric with Latitude.sh's bare metal and GPU compute, the platform eliminates the fragmentation that has plagued enterprises trying to stitch together compute, connectivity, and cloud. One platform. One API surface. One commercial relationship.

Why This Matters Now

  • Equinix Metal is sunsetting June 30, 2026 — creating an immediate migration pipeline worth tens of millions in displaced ARR
  • AI/GPU demand is accelerating — Latitude.sh offers NVIDIA H100, A100, L40s, and Blackwell-architecture RTX Pro 6000 on bare metal
  • Cloud repatriation is real — enterprises report 30–40% TCO reductions by moving workloads to dedicated infrastructure
  • The combined TAM exceeds $50B and is growing at 20–40% CAGR across both bare metal and NaaS segments
Bottom Line The architecture and sales team has a once-in-a-decade platform convergence opportunity. The window is open: Equinix Metal customers need a new home, AI workloads need GPU bare metal with private connectivity, and no other vendor offers both compute and network as a unified service.

Platform Deep Dive

▾

Megaport Core Products

Megaport operates the world's largest independent Network-as-a-Service platform — software-defined connectivity across a global SDN fabric.

NaaS Ports

Physical on-ramps to the Megaport SDN fabric. Available in 1G, 10G, and 100G capacities. The foundation of every deployment — you need a Port before any virtual service.

NaaS Virtual Cross Connects

Private Layer 2 connections between any two endpoints on the fabric. Point-to-point or point-to-multipoint. Provision in minutes, not months. No physical cross-connect fees.

NaaS Cloud Router (MCR)

Virtual Layer 3 routing — now at 100G. Supports BGP, NAT Gateway, packet filtering, IPsec. 42% YoY MCR/MVE deployment growth. Multi-cloud without physical routers.

NaaS Virtual Edge (MVE)

Run SD-WAN and firewall appliances natively on fabric. Cisco, Fortinet, Versa, VMware, Aruba, Palo Alto. Zero hardware deployment.

NaaS Megaport ONE

Unified platform experience: single control plane for provisioning, monitoring, and management across all Megaport services.

NaaS MegaIX & Internet

MegaIX: Internet Exchange for direct peering. Internet: BGP-enabled services expanding TAM beyond pure private connectivity.

Latitude.sh Core Products

Instant, API-driven bare metal compute — from CPU workhorses to GPU-accelerated AI infrastructure.

Compute Bare Metal Servers

AMD EPYC 4th/5th Gen (4484PX, 4564P, 9275F). From $0.37/hr to $3.52/hr. Deploy in minutes via API or Terraform. Full root access, no hypervisor overhead.

Compute GPU Instances

NVIDIA H100, A100, L40s, RTX Pro 6000 (Blackwell architecture). H100 at ~$3.37/hr. Built for AI/ML training, inference, and rendering.

Compute GPU-Accelerated VMs

Quick-start virtualized GPU plans. Cloud-like flexibility with GPU power. Ideal for dev, testing, and smaller inference workloads.

Platform Kubernetes on Bare Metal

Managed K8s clusters on dedicated hardware. Bare metal performance with K8s orchestration. No shared infrastructure.

Storage NVMe Storage Suite

Globally distributed NVMe-backed storage: Object, Block, and File. High-throughput, low-latency, adjacent to compute.

Platform Terraform & API

Full IaC via Terraform Provider. REST API for programmatic provisioning. Managed PostgreSQL for databases. Private Interconnection to AWS, GCP, Azure via Megaport fabric.

Architecture Focus Areas

▾

Priority 1: Reference Architectures

Blueprints every SA should have ready. Each maps a real customer need to a concrete platform deployment.

P1 Hybrid Cloud

Latitude bare metal → MCR → Cloud (AWS Direct Connect, Azure ExpressRoute, GCP Partner Interconnect). The bread-and-butter architecture for enterprises running workloads across bare metal and public cloud.

P1 Multi-Cloud

Single Latitude deployment connected to multiple clouds via MCR. One bare metal cluster, three cloud connections. Centralized processing, distributed services.

P1 AI/ML Infrastructure

GPU clusters → private high-bandwidth links → cloud data lakes. Train and infer on H100/A100 GPUs. Pull training data from S3/GCS over private links. No public internet, no egress surprises.

P1 Edge Compute

Latitude servers at edge DCs → Megaport fabric backbone. Low-latency compute at the edge with reliable backhaul to core infrastructure.

Priority 2: Automation & Developer Experience

  • Terraform modules combining Megaport + Latitude providers into composable infrastructure stacks
  • API integration playbooks with runnable examples for common provisioning workflows
  • CI/CD pipeline templates for infrastructure provisioning (GitHub Actions, GitLab CI)
  • Self-service portal demos showing how customers build internal platforms on the combined API

Priority 3: Security & Compliance

  • Private connectivity eliminating public internet exposure for all inter-site and cloud traffic
  • MVE integration for SD-WAN and firewall at the edge (Cisco, Fortinet, Palo Alto)
  • IPsec tunnels on MCR for encrypted transit, even over private links
  • Compliance positioning for regulated industries: fintech (PCI DSS), healthcare (HIPAA), government (FedRAMP adjacency)
Architecture Team Investment The highest-leverage deliverable is a Terraform module library that provisions a complete Latitude + Megaport stack in one terraform apply. It becomes the demo, the proof-of-concept, and the production starter kit. Invest here first.

Objection Handling

? "We already use AWS/Azure/GCP"
This complements cloud — it doesn't replace it. Private connectivity via MCR enhances cloud workloads: lower latency, no egress costs, better security. Many customers run 60/40 cloud-to-bare-metal and connect them privately.
? "Bare metal is complex"
Latitude.sh has cloud-like UX with API, Terraform, and managed K8s. Deploy a bare metal server in under 5 minutes. This is cloud-native bare metal with full automation, not the bare metal of 2015.
? "Megaport is just networking"
Was networking. Now compute + network in one platform. The Latitude acquisition created an integrated CaaS + NaaS offering. One API, one bill, one support team.
? "GPU pricing is higher than cloud spot"
Dedicated hardware = predictable performance. No noisy neighbors, no spot interruptions, no capacity throttling. For production AI inference, reliability beats spot savings. And you get compliance-ready private connectivity included.
