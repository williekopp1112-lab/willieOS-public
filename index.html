My name is Willie Kopp. I’m a builder who spent the last year designing and shipping a personal AI operating system called Gary. Gary isn’t a chatbot — it’s a dispatch layer that routes tasks to specialized agents, manages multi-phase project execution, and produces real, polished deliverables autonomously.

What drives me is the gap between what AI can theoretically do and what people actually ship with it. I wanted to close that gap for myself first — build systems that actually work, produce artifacts worth sharing, and run at a pace no single person could match manually.

The 96 artifacts in this portfolio are the output of that system. Strategy decks, product specs, discovery frameworks, creative narratives, engineering blueprints — all built with Gary, all real, all mine.

Architecture X-Ray

The technical reason Gary feels like software, not a prompt.

The NotebookLM breakdown makes the pattern clear: Gary is a small operating system. It separates interface, native engine, local memory, and tool execution so autonomous work can be fast, visible, and bounded.

01

Atomic tools become skills.

Single MCP actions can be chained into persistent workflows, with outputs from one step passed into the next.

02

Models are routed by job type.

Interactive chat, background jobs, result summaries, design, and code execution can each use the right engine.

03

Guardrails protect autonomy.

Debounce, concurrency locks, cooldowns, and daily caps keep background work from turning into runaway work.

04

Pixel agents make work tangible.

Silent dispatches become visible states: idle, working, thinking, success, or error. That visibility builds trust.

Not a chatbot.
An operating system.

Gary isn’t a single AI assistant — it’s an orchestration layer with a shell, engine, memory store, and tool sidecar. The UI makes work legible; the native core manages processes; SQLite preserves context; MCP standardizes action.

I describe what I need in plain English. Gary decomposes it into phases, chooses the right model and tool route, dispatches specialists, threads context forward, and produces a polished artifact.
